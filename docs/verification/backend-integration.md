## Run

From `backend/`: `npm ci --ignore-scripts`, then
`node scripts/check-backend.mjs`. Runner uses installed pinned TypeScript, never
downloads tooling. Native and compiled suites run unpiped with inherited output;
nonzero exit stops the check. Compiler output uses a unique ignored `.scratch/`
directory, removed on success or failure.

## Fidelity

Walking fixture uses explicit synthetic telemetry and frame metadata, not pixels,
real detection or flight feasibility. Bootstrap planner mapping is an immutable
test seed and reviewed fingerprint, not dynamic production registration. Iris
reply is a scripted loopback HTTP fixture, marked `local-http`, never provider
inference. Receipt stages are separately supplied fixture-producer facts.

Default CLI still starts bridge only. Programmatic startup permits a trusted
pre-reviewed fixture seed, enabling callers to attach the existing coordinator
to the same authority. No service jobs or heartbeat are generated by startup.
